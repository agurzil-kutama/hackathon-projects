# FireScope Data Contract

This is the agreement that lets all team members work in parallel. The Web Developer will build the UI against the mock file. The Data Scientist will produce the real file in this exact same format.

## Final File: `harmonized_monthly.parquet`

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `cell_id` | string | ID of the 1km grid cell |
| `lat` | float | Cell center latitude |
| `lon` | float | Cell center longitude |
| `year` | int | Year of the observation |
| `month` | int | Month of the observation (1-12) |
| `count_raw_modis` | int | Raw MODIS hotspots in that cell and month |
| `count_raw_viirs` | int | Raw VIIRS (Suomi-NPP) hotspots in that cell and month |
| `count_harmonized` | float | MODIS-equivalent harmonized count (The main metric) |
| `median_month` | float | Historical median for that cell and calendar month |
| `anomaly_pct` | float | Percent difference from the median |

## Rules
- **Do not commit large data files** to GitHub. They will be shared via Google Drive.
- **Mock File:** A `mock_data.parquet` file will be generated by the Lead and given to the Web Developer to build the API and Map.
- **Real File:** The Data Scientist will generate the real `harmonized_monthly.parquet` by Nov 8.
